# Code of Conduct

## Our standard

We are building a tool whose whole point is honesty about evidence. Behave the
way good researchers do in a lab: critique ideas and outputs, not people.

**Expected:** be kind and precise; cite sources when correcting someone; assume
good faith; keep criticism about artifacts (extractors, fixtures, templates).

**Unacceptable:** harassment, discrimination, personal attacks, publishing
others' private information, bad-faith claims of "reproduction" without
protocol checks, or sharing leaked credentials/datasets in issues.

## Scope

Applies to the repository, issues, PRs, and any project space (including the
Hugging Face Space community tab).

## Enforcement

Report violations to the maintainers via GitHub (or the contact in
SECURITY.md). Maintainers may remove comments, block accounts, or reject
contributions that violate this document. Repeated or severe violations result
in a permanent ban.
